# Diabetes Progression Project Portfolio

## Scenario and question
Scenario 1: Understanding Diabetes Progression. This project examines associations between patient characteristics and a continuous measure of diabetes progression one year after baseline.

## Files to submit
- `diabetes_analysis.R` - commented, reproducible R script.
- `Diabetes_Progression_Report.pdf` - analytical report organised around the six project questions.
- `Decision_Maker_Presentation.pptx` - five-slide summary for a non-specialist decision-maker.
- `diabetes.tab.txt` - supplied dataset required to run the script.
- `figures/` - selected figures used in the report.

## Reproduce the analysis
Place the R script and data file in the same folder, open the script in RStudio, and run it from top to bottom. The script checks for the data file and will ask you to select it if it is not in the working directory. It creates a `project_outputs` folder containing tables and diagnostic plots. Required R packages: `ggplot2`, `dplyr`, and `broom`.

## Submission
Upload this ZIP (or its contents as an organised folder) to the course submission area. The minimum required items are the `.R` analysis file, PDF report, decision-maker presentation, and this README. Include the dataset in the ZIP so the script can be rerun. Check that the instructor can access the uploaded files.

## Interpretation note
The data are observational. The results describe associations and do not establish causality or provide an individual clinical decision rule.
